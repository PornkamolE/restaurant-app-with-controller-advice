# restaurant-app-with-file-exporting
---

## Features Implemented

1. เพิ่ม file exporting feature ใน:
   - ManagerService
   - ManagerController
   - ManagerRestController

2. ปรับ `manager-dashboard.html` ให้ผู้ใช้งานสามารถเลือก export ได้ทั้ง:
   - CSV
   - Excel
   - JasperReport (PDF)

3. สร้าง `resources/orders.jrxml` เป็น template สำหรับ JasperReport
